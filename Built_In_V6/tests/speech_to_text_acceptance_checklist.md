# 独立语音转文字实机验收

分支：`feature/voice-to-text`，从已确认基本正常的 `df157be` 建立。
构建配置：`Invoke-P4Build.ps1 -Profile sign`；开发板 COM20。
新增 `CONFIG_P4_ASR_MODE`，稳定 display 配置不启用。

## 工作方式

- 首页新增“语音转文字”；保留原语音对话和手语翻译入口。
- 进入后暂停原对话播音/字幕，保留 RTC 和空闲零 PCM 节奏。
- 独立 ASR 使用 16 kHz / 16-bit / mono PCM、200 ms 包、gzip 和二进制序号。
- 按住才采集；松开或触点移出停止采集，负序号末帧结束本次请求。
- 首版每次最长 60 秒。连接期间录音缓存在有界 PSRAM，避免丢开头。
- 收到全量结果替换临时字幕，最终结果留在页面；不发给 LLM/TTS。
- 只在内存保存本次 PCM，不保存录音/识别原文；诊断仅状态码、长度、耗时。
- Key 仅存 Git 忽略的 `secrets/doubao_asr.h`；WebSocket 底层请求头日志被屏蔽。
