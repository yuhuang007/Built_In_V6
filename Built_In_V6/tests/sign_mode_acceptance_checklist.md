# 手语预览入口实机验收

适用分支：`feature/sign-language-mode`。构建/烧录使用
`tools/Invoke-P4Build.ps1 -Profile sign`，目标 COM20。
这是摄像头预览入口，尚未接入手语识别模型。

## 验收顺序

| 检查 | 预期 | 结果 |
|---|---|---|
| 冷启动 | 原语音首页，底部有“手语翻译”；未点击时无 CSI/ISP 初始化或摄像头缓冲申请日志 | 待用户确认 |
| 首页语音 | 按住有 ASR，松开后单次回复，字幕和扬声器正常 | 待用户确认 |
| 回答中打断 | 再次按住可中断并完成新一轮 | 待用户确认 |
| 录音或初始化任务忙时点击手语入口 | 提示等待当前任务结束，不启动摄像头 | 待用户确认 |
| 未录音时点击手语入口 | 云端滞后的回答/思考状态不阻止切换；先停止旧播放并确认扬声器空闲，再启动摄像头 | 待用户确认 |
| 空闲时点击手语入口 | 切换到预览，1920×1080 全画幅缩小至 960×540，按需初始化摄像头 | 待用户确认 |
| 约 30 秒预览观感及返回后基本语音 | 画面可正常预览，返回后字幕和扬声器正常 | d2f28be：用户回复“目前是正常的”；数值帧率未采得 |
| 预览运行至少 60 秒 | 无意外重启、栈溢出、panic、卡死；观察镜像、白平衡、视野、撕裂和帧率 | 待用户确认 |
| 点击“返回语音” | 工作线程停止 CSI/AWB/ISP 并释放相机缓冲；无整机重启返回原首页，正常网络下复用 RTC，不重新注册或播放欢迎词 | fd26a7a：串口释放资源、retained_session=1；用户确认不再重连或播放欢迎词；d2f28be 基本回归反馈正常 |
| 返回后的语音 | ASR、单次回复、扬声器、回答中打断正常 | d2f28be 基本语音回归反馈正常；打断及完整逐项验收待确认 |
| 重复进入/返回 5 次 | 每次能进入预览、无重启返回首页；记录每次释放后的 PSRAM，不持续下降 | 待用户确认 |
| 摄像头启动中点击返回 | 完成受控清理后返回，按钮重复点击不重复销毁资源 | 待用户确认 |
| 启动失败后点击返回 | 错误页仍可返回；驱动停止失败则提示手动重启，不强行释放资源 | 待用户确认 |
| 预览中真实断网后返回 | 记录连接失效，返回后走原有网络恢复；不把已断开的会话当成可用 | 待用户确认 |

## 判断边界

- 串口启动正常不能替代用户对屏幕、声音和触摸的确认。
- 旧版返回曾主动重启；本轮改为无重启启停，必须重新完成五次循环和返回后语音验收。
- 预览统计使用 `timing: shown_fps/cache_us/scale_us/display_us`，不能用采集帧率替代显示帧率。
- 正常模式切换不得销毁 RTC；预览期间只发零 PCM 保持原节奏，不采集麦克风或上传图像。
- 模式切换通过后再单独处理画面略暗；不要同时调亮度、白平衡和语音。
- 记录状态、耗时和内存即可，禁止记录凭据、云端身份或用户对话内容。
