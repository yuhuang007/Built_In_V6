# 手语模型实验与部署

## 先明确任务

区分检测/姿态前端、孤立词分类、词序列自然成句、连续句级翻译。不能将加载句级模型、检测出身体点或语言润色当作词识别已解决。保留原始确认词、用户编辑和拒识，生成文本不能补猜丢失词或从乱句截取对词算成功。

具体模型路线随用户最新决策更新，不自动恢复PDF规则扩词、mT5整句路线或全量CSL-News下载。PDF可作为词义动作参考；模型源码、预训练权重、训练数据分别核实。

## 实验设计

开工前写清一个待检验假设、对照基线、真实数据、指标、候选数/预算和结束条件。复用已有环境、权重和缓存。两次候选是历史任务预算的例子，不是永久固定次数；本轮按任务制定有限预算。

- 按人物、源录制分组；同源视角、相邻帧和增强不能跨训练/评估制造新样本。
- 有序JPG可做有边界序列实验，未知FPS和完整动作覆盖须标注，不能因缺MP4一律停止，也不能伪造时间戳或复制帧凑长。
- 核对标签ID、动作来源、预处理、镜像、左右/跟踪槽位、身体参照、缺失掩码、采样与动作起止；训练和在线运行采用相同处理或说明差异。
- 按开发集选模型；已被反复查看的P09/P10等不能再称首次盲测。不以已观察测试集挑最高分。
- 评估分列全词、旧词、新词、输入失败及未知动作；注明分母、运行者、实际权重和条件。
- 交付可运行入口，独立保留旧模型；离线高分仍需真实摄像头检验。用户定性好坏反馈均保留，不编造准确率。

同类训练无稳定收益时重新检查输入、任务匹配和真实分布，不自动归因于用户或继续扩大网络。必要核查以决定下一步为终点，不重建全套审计系统。

## 部署可行性

依据实际板端剩余内部内存、PSRAM、Flash、算子和运行时判断。不能用总PSRAM作为模型预算，SD不是运行内存，LoRA不移除基座，ONNX不自动缩模。

P4＋电脑联调逐步验证：采集→编码→传输→解码→姿态→分类/生成→回屏/确认。完整视频接口不能假定接收JPEG帧；片段ID、结束、取消、超时、有限队列和迟到结果必须有明确语义。保留图像方向/色序/采样一致性。

计时分段并覆盖整链，P50/P95注明样本量和条件；仅分类头毫秒耗时不能冒充视频处理或P4端到端延迟。先用已有资源做必要测量，再决定新增训练或设备。
