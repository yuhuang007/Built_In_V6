# 固件开发、界面和回归

## 构建与版本

改代码前执行 `git status --short --branch`、`git log --oneline -n 5`；保留用户及未知改动，不要求为了开工先提交全部文件。按已有约定仅提交本轮功能文件，再构建，避免混入缓存、秘密和其他记录。

在项目根使用：
```powershell
.\tools\Invoke-P4Build.ps1 -Action build -Profile sign
```
只有当前任务包含烧录授权且端口核对无误时，再使用：
```powershell
.\tools\Invoke-P4Build.ps1 -Action flash -Profile sign -Port COM20
```
COM20是既有端口，实际连接变更时重新核对。不要因阅读到该命令自动执行烧录。纯文档/Skill改动不构建或烧录固件。

构建前后检查相关依赖锁、sign/display配置和分区；当前记录锁为 ESP-IDF 5.5.4、esp_wifi_remote 1.6.5、LVGL 9.6.0~1、Hosted 2.12.13。它们是受保护基线；升级是独立明确任务，不从工具报错擅自升级。记录实际编译版本、镜像大小/摘要和最小应用分区余量，不用大OTA槽掩盖factory限制。

## 范围与资源

- 相机、显示、音频、网络等默认单独修改，必要接口调整写明影响面。保留欢迎词、模式资源交接、初始化保护和已经验证的恢复路径。
- 不通过擦Flash/NVS、格式化SD、关闭TLS或栈保护掩盖故障。C6维护、分区和硬件接线须依据本次任务及真实资料。
- 内存检查不仅看总空闲，还看最大连续块、任务栈、持有对象和释放顺序。外部PSRAM与内部/DMA内存不可混为一谈。

## UI方法

先确认屏幕实际逻辑尺寸、方向、字体度量和用户最后反馈。显示与相机方向独立，不累计历史口头旋转角。按最新记录保留大字正文、嵌入式输入、物理键盘不抬页、候选浮层及既有功能颜色，除非用户要求改变。

布局先检查几何、锚点、父子对象所有权、焦点与生命周期，再用实屏检查中文缺字/裁剪/遮挡、窄长内容、软键盘、重复切页。审美围绕可读性、触控、对比度和稳定刷新，不照搬网页卡片或昂贵动画。

## 回归选择

| 改动 | 必要关注 |
|---|---|
| 字体/布局/键盘 | 缺字与裁剪、候选、触摸、反复展开收起、草稿、内存释放 |
| 相机/刷新/方向 | 视野色彩、提交吞吐与撕裂、进入退出、返回语音、首次重启 |
| 音频/RTC | 首页后完整欢迎、按住录音/松开发送、单次回复、播放打断 |
| 网络 | Wi-Fi→时间→TLS→注册→RTC→业务；重连与模式恢复 |
| 息屏/启动 | 欢迎与初始化保护、首次输入只唤醒、常亮对照、恢复播放 |

测试覆盖与改动风险相称，不为纯配色强行新增实现镜像测试。固件自动测试通过后，只补必要的实机检查；没有新变化或疑点不反复全量测试。

串口用既有白名单数值诊断，短时按需观察、结束释放；未复现故障的窗口不能排除候选原因。测量的软件提交帧率、DMA间隔不等于光学端到端延迟或目视验收。
