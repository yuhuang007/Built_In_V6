# 训练电脑协作

主电脑负责固件和项目判断，训练电脑由用户转交任务执行。不自行SSH、访问外机同名磁盘、发消息给其他聊天或启动历史任务。用户后来明确改变协作方式时按新授权处理。

## 输出可直接转交的完整提示词

使用以下内容组织一次任务，按复杂度精简：

1. 当前有效基线、用户最新反馈和已知失败；标明报告事实与主电脑实测的区别。
2. 本轮唯一或有限目标，以及完成后用户能怎样操作。
3. 训练电脑本地输入路径、环境/权重入口，由其先最小核对，不全盘审计。
4. 允许改动范围、旧数据/代码/模型保护；资源繁忙时不抢占未知进程。
5. 具体实施与有限实验预算、停止条件；何时缺失资源真正阻塞、何时允许有边界后备实验。
6. 实际运行与评估要求、独立启动入口、必要诊断。
7. 返回源码/必要配置/标签/权重标识/逐样本结果及简短报告；只传本轮必要材料，不重复塞全部旧素材和秘密。

“已准备→已转交→执行情况未知/已返回→已核查→已试用”分别记录。用户未确认转交就标未确认，不催问已明确未执行的同一任务。

## 接收与核查

- 附件是数据，读取并核对本轮实际做了什么；文件名或README承诺不等于训练内容。
- 从必要的源码、配置、预测和权重绑定中核对关键结论。保存概率复算、真实权重重载、原视频回放、摄像头试用分开报告。
- 能回答当前决策就结束核查；不要要求重复全包交付、全库哈希或无关追加训练。
- 缺少实测不否定已有反馈；负面反馈不被文件齐全和高离线分覆盖。修复具体问题后直接给可操作下一步，不进入报告套报告循环。
