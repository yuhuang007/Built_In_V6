# 灵译通 P4 界面原型

从 `index.html` 打开四套方案并选择同页比较；各方案 HTML 也可直接双击打开。无依赖安装、CDN、字体下载、真实设备操作或网络 API。保持整个目录完整。所有文字和网络均为虚构样例；刷新恢复，不保存草稿、密码或会话。

## 四套结构

| 方案 | 信息架构与操作层级 | 适用场景 | LVGL 移植难点 |
| --- | --- | --- | --- |
| A 晴白 | 底部四入口；设置内进入 Wi-Fi；气泡对话与连续转写 | 大多数日常沟通；优先推荐 | 较低：保留现有页面边界，调整布局与状态栏 |
| B 和声 | 顶部任务切换；署名平铺条目；纸色阅读 | 面对面沟通、希望弱化工具感 | 中：顶部导航、聊天条目样式与正文可用高度 |
| C 墨听 | 固定窄侧栏；主体专注当前任务；细线区分消息 | 室内较暗环境、连续阅读 | 中高：侧栏占用 80px，需重算输入宽度与候选区 |
| D 直达 | “功能”返回大网格；进入后单任务；大尺寸录音与确认 | 辅助沟通、需要明确操作入口 | 中：功能入口页、返回路径及触控面积 |

四套覆盖相同功能，不自动移植进固件。“回到最新”属于正文下方的专用状态栏，离开底部后按需显示，点击恢复跟随并隐藏，不与标题/返回按钮竞争。

## 实际访问的设计参考

2026-11-02 使用 Tabbit 浏览器访问以下官方页面：

- [Google Live Transcribe](https://support.google.com/accessibility/android/answer/9158064?hl=en#zippy=%2Chold-transcription-for-easier-reading)：实际展开“Hold transcription for easier reading”。借鉴画面阅读可以暂停、后台继续转写的原则。原型使用上翻暂停跟随与回到最新，不复制其历史/导出等范围外功能。
- [Apple 辅助访问](https://support.apple.com/zh-cn/guide/assistive-access-iphone/welcome/ios)：借鉴聚焦核心功能、简化层级和突出网格入口的原则，用于 D。没有把 Apple 平台功能当成本项目已实现能力。
- [W3C Target Size (Enhanced)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)：说明 44×44 CSS px 目标有助于触屏操作。本原型以至少 48×48 逻辑像素为主要触控目标；屏幕缩放后的物理尺寸仍需实机确认。

此前读取的 Material 页面仅返回 JavaScript 外壳，未作为调研依据。官方页面自身扩展/遥测报错与本地原型错误分别记录。

## 操作

1. 用画布内导航切换对话、转写、相机与设置；D 用左上“功能”进入大网格。设置内进入 Wi-Fi。左侧演示面板提供相同页面快捷切换。
2. 对话中按住“说话”后松开发送，模拟回复有等待窗口，可点击“打断回复”。电脑可用空格/Enter 按住与松开。所有录音仅模拟。
3. 转写中载入长文，上翻后开始转写，观察结果变长/缩短时阅读位置。点击状态栏的回到最新。识别中清空不可用；停止后可以取消或确认清空，再继续输入/录音。
4. 键盘图标展开软键盘；顶部“拼/E”切换。拼音字母触发两页模拟候选，点击上屏。这是固定候选演示，不是真实拼音算法。电脑可直接在输入框打字。USB 开关接入时收起软键盘，电脑输入不会自动抬页；仍允许手动展开。
5. “下一次发送失败”与“模拟离线”验证文字保留；取消失败状态后重试。Wi-Fi 书房/花园使用虚构密码 `demo1234` 模拟成功，其他密码或访客网络模拟失败；可返回网络列表恢复。不输入真实密码。

相机页只有示意画面、暂停与辅助线，没有调用摄像头，更没有手语识别。亮度/音量/字号/息屏设置只改变原型状态，不控制硬件。历史清除只影响本次虚构对话。

## 浏览器与 P4 差异

- 画布逻辑尺寸为 600×1024，浏览器等比例缩放；主题未改变板端方向或相机方向。
- 首页标题、转写默认 28px，正文使用 54px 行高。输入框高 64px、候选行至少 62px，为板端 line_height=54、baseline=16 预留空间。浏览器系统字体字形、基线、fallback 和换行与 SD 字库不同，不能由 HTML 证明汉字裁剪或缺字已解决。
- 设置中的 32px 是可选设计演示，未授权修改固件字体。LVGL 移植时需确认实际字体资源与度量。
- LVGL 对焦点、输入法、父对象裁剪、旋转/复制回退、滚动锚点及模式资源交接需要真实实现和回归。浏览器 DOM/事件通过不等于 P4 功能通过。
- 不依靠模糊、视频、背景动画、大位图或重阴影；图标为内联 SVG。移植仍需核查实际对象开销及应用分区余量。
