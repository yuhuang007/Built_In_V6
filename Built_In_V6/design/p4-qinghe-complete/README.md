# 青禾 · 完整界面设计

本轮按用户选定的青禾布局完善电脑原型，取消底部导航，覆盖开机、欢迎、首页、语音对话、独立转写、相机、设置、Wi-Fi、帮助、关于、离线和息屏。未修改公共固件、secrets、依赖或分区；无构建、提交、烧录及 COM20 操作。

## 打开与体验

- [完整开机入口](index.html)：约六秒加速视觉演示，随后可点击各页面；不播放真实声音。
- [全流程设计板](storyboard.html)：16 个页面/状态的静态图，点击进入相应可交互原型。
- [P4 动效落地规范](P4-MOTION-SPEC.md)：动画预算、真实源码约束、事件门禁与未来板端验收。
- [页面总览](previews/overview.png)、[浏览器核验结果](browser-verification.json)。

双击本地 HTML 即可打开，无服务、CDN、运行依赖。页面左侧为电脑评审工具，含重看开机、欢迎、息屏、模拟 USB/离线/失败、转写修订；不作为正式产品菜单。

建议按以下五步评审：

1. 从开机入口体验点阵、三段准备、欢迎、进入首页。侧栏可选择离线或文字资源较慢情景重播。
2. 点击首页语音卡片，按住说话后松开，体验回应/打断；左上返回，确认前进/返回纸幕方向。
3. 进入转写，载入长文，上翻后修订几句，再点回到最新。点清空并取消，随后确认清空，再输入或录音。
4. 展开键盘输入 nihao，体验候选与拼/E；模拟 USB，确认不自动弹软键盘。可模拟下一次发送失败检查草稿。
5. 浏览相机、设置、Wi-Fi、帮助、关于；息屏后点击一次仅唤醒。勾选减少动态效果比较静态替代。

## 视觉和交互

奶油白 #F5F6ED、卡片白 #FFFEF8、鼠尾草绿 #E2E9D4、深绿 #3E5947；暖褐用于连接提醒，暗红仅用于破坏性确认。首页保留语音主卡片与转写/相机双卡片。所有内页左上返回首页；Wi-Fi、帮助、关于返回设置。没有底部导航。

逻辑画布 600×1024，正文/内页标题 28px、正文行高 54px；输入框 64px，候选行至少 62px。候选使用独立预留区，回到最新在正文下方，不覆盖内容与录音。软键盘出现时允许压缩阅读视口，核验中仍有约 210px 正文高度；USB 不自动展开软键盘。草稿仅在本次页面会话内存中保留，不写本地存储。

转写底部跟随、上翻保位、持续修订长短变化、回到最新、取消/确认清空沿用此前本地交互模型。识别中不能清空；确认后可继续录音和输入。真实业务仍需由固件现有模型负责，不将原型定时器替代录音和云端事件。

## 动效参考与取舍

本轮实际访问 [ascii.rest](https://ascii.rest/)、[progress bar](https://ascii.rest/progress-bar/)、[spinners](https://ascii.rest/spinners/)。网站标示的进度示例为 48×11、30fps；spinner 示例为 66×13、12fps。借鉴分段准备状态、局部节奏、减少动态效果的静态替代；没有复制其代码、字体、动画资产，也没有引入 ascii.js。禾苗点阵和切页幕由本项目自行绘制。网站的网页字节数和 FPS 不作为 P4 内存或性能保证。

青禾的视觉起点是此前用户选中的 04 AI Translator 方向；原作来源在 [上轮选择说明](../p4-ui-fusions-selected/README.md) 与 [参考板](../p4-ui-new-selection/index.html) 中保留。新页面未使用第三方作品截图或插画。

## 核验和边界

Tabbit 核验覆盖启动/欢迎门禁、多帧切页、快速连点保护、八页布局、语音/打断模拟、转写阅读/修订/清空、输入/候选/USB/失败草稿、离线与息屏首触。详见核验 JSON 与 verify-experience.js。

独立 Edge 无头进程、专用临时 profile 渲染 600×1024 页面 PNG；实际看图后修正黑屏背景和相机 SVG 的样式优先级。它们不是 Tabbit 截图或 P4 实屏图。

本机源码 HEAD 为 1d56520。板端基线来自上轮启动 ELF hash 及用户欢迎/对话有声音反馈：1d56520 / 004；本轮未重新读板或烧录。未执行固件回归测试。浏览器字体、虚构文本、网络和相机不代表 SD 字库、真实麦克风、云服务、相机识别、PPA/CPU 路径、模式资源交接或真实触屏验收。旧中文缺字事项仍待复现。
