# 联网工具网关

P4 不直接抓取任意网页。它只向受控网关发送意图和少量参数；网关负责 API 密钥、联网搜索、缓存、限流和结果清洗。这样音频、显示与后续 MIPI 摄像头 DMA 保持在 P4 侧，网络检索的失败不会拖垮实时会话。

## 第一阶段接口

`POST /v1/tool/query`

请求：`{"tool":"weather|search","query":"...","locale":"zh-CN"}`

响应：`{"ok":true,"answer":"适合直接显示/朗读的简短中文","source":"...","cached":false}`

约束：

- 设备端请求和响应均限制为 2 KiB；连接、读取总超时不超过 4 秒。
- 网关缓存天气 10 分钟、搜索 5 分钟；同一设备最多 6 次/分钟。
- 生产部署必须使用 HTTPS、令牌鉴权与允许来源校验；不得把搜索/天气密钥编译进 P4 固件。
- 失败时返回简短可读提示，P4 随即回到普通对话，不阻塞麦克风或 LVGL 任务。

## 启动边界

默认启动只监听 `127.0.0.1:8787`。这是当前开发机自检模式，P4 无法访问。

在 `secrets/qianfan.env` 增加独立的 `GATEWAY_DEVICE_TOKEN` 后，才允许在受控局域网用 `--host 0.0.0.0` 测试；该令牌只用于 P4 到网关的鉴权，绝不能等同或复用千帆 API Key。实际部署仍应由 HTTPS 反向代理终结 TLS，并限制只允许开发板 IP。

## 与手语功能的边界

摄像头帧、手势骨架和模型推理不经过这个通用文本接口。后续视觉服务使用独立的 `/v1/vision/sign` 流式协议与帧率/分辨率预算，避免搜索响应占用视频路径。
