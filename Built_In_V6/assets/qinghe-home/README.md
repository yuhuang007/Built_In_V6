# 青禾静态首页资源与布局

`layout.json` 是600×1024逻辑画布的首页布局数据，来源为现有青禾原型DOM/CSS的实测坐标，已经除去浏览器缩放。`tools/Generate-QingheHome.py`生成固件布局表、透明资源和两份布局预览；`qinghe_home.c`实际读取该表建立LVGL对象，没有把整个页面烘焙到固件。

- `layout-preview-14.png`、`layout-preview-28.png`是**布局预览**，不是LVGL帧缓冲或P4实屏截图。矩形、颜色、静态波形和A4资源与固件相同；普通文字用现有SD字库的Source Han Sans源字体近似排版，LVGL字形定位、RGB565混色及实际面板效果以实机为准。
- 固定文案准确为“慢慢说，我在听”（2026-11-04按用户要求去掉句号）。从Windows本机`C:/Windows/Fonts/msyhbd.ttc`（Microsoft YaHei Bold）以44px离线光栅化，量化为4bit透明度，352×56，共9856B；缩短文案在原透明资源内居中。未分发字体文件、生成完整字库或对标题运行时缩放。此资源仅表达固定装饰文案，不替代动态业务正文。
- 6个24×24线条图标各288B，另有16×16帮助箭头128B；标题和图标总11712B，不含描述结构。线条图形由生成器绘制，波形是一个LVGL绘制对象上的11根静态圆角条，无装饰动画/定时器。
- 继续借用既有`assets/brand/native-icon-64.png`与`qinghe_logo_64`，未重绘或替换用户原生Logo。
- 普通中文文字使用现有14/28px字体，实际行高27/54。产品名、主按钮和两张次卡标题保持28px；固定宣传标题独立44px。28px设置仍作用于普通首页文字，胶囊会扩大，不借此缩小或隐藏设计。
- 原型胶囊约162×33，板端默认226×44、28px模式368×58；次卡从约263×155调整至263×180，容纳真实行高。主卡14px模式540×310、28px模式540×326，主按钮496×68；USB说明固定于底部安全区（y936，底部留34px）。原生Logo64px（原型点阵48px）。这些是具体几何差异，不作为遗漏设计元素的理由。
