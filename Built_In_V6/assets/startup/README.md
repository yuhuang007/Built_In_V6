# 开机 GIF 与阶段进度

用户提供循环 GIF，用于本项目启动页。此目录仅包含派生资源，不改原下载文件。
来源网站标识不等于明确的再分发许可；商业发布前需核对素材授权。

- 原动画：700×700，120 帧，3.6 秒循环。
- 板端：320×320，60 帧，32 色共享调色板，60 ms/帧；保留循环时长及完整画面。
- GIF 嵌入 sign 固件，只读取 flash，不依赖 SD 或网络。
- RGB565 解码画布约 200 KiB，另有解码器及 16 KiB 解码缓存开销；启动页删除后释放。
- 开机中文说明使用 24px 小型内置字库，不等待 SD 字库。
- 页面与动画均为黑底；中性色反相使地图线条可见，彩色主体保留。
- 进度条上方只显示一行当前阶段。LVGL 9.6 循环次数设置为 0（无限循环），
  不使用负数，负数会在一轮结束后暂停。

`tools/Generate-StartupAssets.py` 使用已有 Pillow 和 E 盘 `lv_font_conv` 生成
GIF、覆盖所有启动说明的内置字体、资源 SHA/帧时序清单及抽帧预览；不安装依赖。

进度为完成阶段的权重，不是下载字节或预计耗时：
显示 5%、音频 15%、首页字体准备 15%、Wi-Fi 15%、网络准备 10%、
14px 索引 15%、28px 索引与缓存 25%。字库阶段按实际解析字形数细分推进；
28px 解析最多推进 24%，最后 1% 在缓存创建成功后才计入，进度条动画平滑显示。
同次启动显示值不倒退；网络断开及异常仍由中文状态提示。
字库仍在解析时，不再因满 20 秒而强制离开动画页；字体任务结束后允许联网超时回退，
整个启动页保留 60 秒异常上限，不伪造 100%，未完成资源继续后台准备。
完成时先显示真实完成值一个 UI 间隔（约 200 ms），随后直接删除 GIF/启动页，不等最后一轮动画，
再沿已验收流程放行欢迎词。

项目内加载器只在创建尚未发布的字体期间使用文件私有 I/O 包装器，
底层 stdio 读取/定位释放显示锁，单次读取最多 16 KiB；LVGL 缓存与元数据仍在锁内。
完成后恢复原驱动，字体绘制时不采用解锁包装器；没有修改共享文件驱动或依赖。

离线检查和抽帧预览不能替代实机 GIF 流畅度、中文可读性、进度及语音/摄像头回归。
