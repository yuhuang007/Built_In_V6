# 14px / 28px SD 字库 V2

文件复制到开发板 SD 的 `fonts/` 目录：

- `P4Z14V2.BIN`：14px，用于转写页状态和按钮；2,954,524 字节。
- `P4Z28V2.BIN`：原生 28px，用于转写正文；10,333,116 字节。
- 保留旧的 `P4ZH14.BIN`，原语音页继续使用旧字库。

采用 8.3 短文件名，兼容当前不启用长文件名的 FATFS 配置。
两套字体均为 LVGL binary / 4bpp / 不压缩 / 无 kerning，按需读取 SD 位图。
正文使用原生字形和有界 PSRAM 字形缓存，不再放大 14px 或缩放整段文本。

## 字符覆盖

两套实际二进制 cmap 均包含相同的 29,861 个字符。
从项目固定 LVGL 组件附带的 `SourceHanSansSC-Normal.otf` 取主要字形，
缺失的常用符号从 `DejaVuSans.ttf` 补充；对应许可证随本目录资产保留。

范围包括 ASCII、Latin-1/Latin Extended、希腊字母、通用标点、货币、单位、
箭头、数学/技术符号、CJK 标点、兼容单位、扩展 A 和基本汉字区、兼容汉字、
竖排标点及全角/半角字符中源字体实际支持的字形。
`sd-fonts-v2-manifest.json` 明确列出实际覆盖及不支持的范围，并记录两套文件的 SHA-256。
这是扩大后的常用字符覆盖，不等于所有 Unicode/emoji/所有罕见汉字均受支持。

## 可复现生成与检查

已有项目 E 盘字体转换工具，无需全局安装：

```powershell
node --max-old-space-size=4096 tools/Generate-SdFonts.cjs
.\.idf-build-env\Scripts\python.exe tests/test_sd_fonts.py
```

生成脚本仅写入本目录资产、清单、许可证和公开的 `sd_font_assets.h`。
测试独立解析实际二进制 cmap、字号/格式，并检查必需字符、两套覆盖一致、大小及 SHA-256。
不能用这些离线检查替代开发板上的清晰度、加载、滑动和切换验收。

## 局域网分段安装

用户选择沿用现有局域网传输方式。临时工具仅提供上述两个字体文件，
限定路径、16 KiB 分段、1–30 分钟生存期，不提供凭据、录音、任意文件或后端业务：

```powershell
.\.idf-build-env\Scripts\python.exe tools/sd_font_server.py --serve --minutes 30
```

私有局域网地址仅在 Git 忽略的 `secrets/sd_font_transfer.h`，不得复制到报告或日志。
电脑多网卡时必须选择开发板可访问的实际物理 LAN/WLAN 地址，不选 VMware 等虚拟网卡。
本机能读取分段不等于开发板可达，不自行修改防火墙或 Wi-Fi 配置。

首次进入转写页，页面显示安装/校验进度，完成后按页面需要调用 14px 与 28px。
只安装缺失的 V2 文件；存在的文件必须通过大小及 SHA-256 校验，不覆盖异常的现有文件。
新临时文件用独占方式创建，校验、同步落盘后才改名；失败/取消仅移除本任务创建的未完成临时文件。
预先存在的同名临时文件不会被覆盖，应先确认来源和内容。
安装失败保留旧字库，返回可取消；不在首页自动下载，不影响开机欢迎词的正常路径。
安装成功后不需要电脑传输服务，后续从 SD 本地加载。

已验证字体的版本哈希、文件大小和 FAT 修改时间保存在板端 NVS 的字体专用命名空间。
后续进入（含重启后）元数据未变化时直接加载，不重复读取约 13 MB 计算 SHA，
不显示安装进度。首次建立记录、文件缺失、版本或元数据变化时才执行完整校验/安装。
记录写入失败不影响本次已验证字体使用，但下次会重新校验。
该快速路径不是逐次介质完整性检测：同大小/同修改时间的内容损坏或换卡不保证被发现；
原生加载失败仍提示回退，不承诺自动覆盖修复现有文件。

启动后台任务预先验证已安装的 V2 文件、解析两套字库并保留索引及有界字形缓存。
缺失文件不在开机自动下载，只在用户进入转写页时沿原流程安装。
退出转写页删除页面及临时回退字体，不释放准备好的原生索引/缓存。
项目内的 `p4_font_loader.c` 基于锁定 LVGL 9.6 的 MIT 加载器，解析字形时约每 4 ms
检查一次是否需释放屏幕锁并让出调度；不是单次 SD I/O 的硬实时上限。
不修改 managed_components，许可证随目录保留；升级 LVGL 时需复核兼容性。
位图仍从 SD 按需读取，不把完整 13 MB 字库读入 RAM；SD 仍须保持插入。
